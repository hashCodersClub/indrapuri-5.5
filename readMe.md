### HTML Tags ?

HTML systax used to target spefic area on webpage.

Types of <b>tags<b> :-

1.  paired - <tag> body</tag>
2.  unpaired - <tag/>

- b[appearance] or strong[appearance + important]
- i or em(recommended)
- paragraph - <p>
- horizontal line - <hr>
  list - <li>
  subscript - <sub>
  superscript - <sup>
  break line - <br>

### Types of URLs

1. Absolute
2. Relative

'/' -> start from the root project
"./" -> start from the current folder
"../" -> start from one directory back
".../" -> invalid url
